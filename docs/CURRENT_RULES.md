# 当前生效规则：单次功能检验

用户最新重复确认：**取消作业后测试，只记录一次检验结果，使用单选点，不使用下拉选单。**

此规则覆盖旧 v0.1/v0.3 文档及深度测试模板中关于 Initial Test／Final Test、ROK 复测全Pass的要求。以后按旧文档审查时，应将这些旧检查要求标记为已被本决定替代，不得把审查或测试任务当成恢复复测的授权。原始参考文档和旧测试报告保留作为历史证据。

- 所有翻新、维修、WFR均只有一份 `Inspection Result / 检验结果`，每项三个单选点：Not Tested／Pass／Fail，中文未检查／正常／异常。
- 同一项目只能选择一个状态。新记录及编辑请求只记录 `checks.initial`，内部键名保留用于兼容已有数据；不再创建新的 `checks.final`。
- ROK要求每个功能项已检查（Pass或Fail），保留检验时发现的异常，不另做复测门禁。翻新要求全部Pass；SCRAP仍需原因；WFR保持未完成、本人续填。
- 旧记录已有 `checks.final` 仅作不可编辑的历史证据，修改请求不能覆盖它。管理员更正已完成记录仍需原因及审计；原已完成ROK的检验未改时可更正备注，不伪造历史检验结果。
- 功能检查报表每个功能项一行检验结果；旧复测存档单列在 Work Summary 的 Legacy Post-work Checks JSON，不计作新的检验阶段。
- 保留本次之前的中英文、账号偏好、原文/手工译文、参考字段、BOM抽屉防重/异步保护、照片、权限及管理员更正修复。
- 用户在2026-10-30已确认标准用量为翻新/维修耗用硬上限，并授权真实BOM导入及测试。按SN扫码后手选型号/版本带入BOM，不能按SN猜型号。硬上限适用于保存、结案与管理员更正，无超耗例外。
- 当前英文品牌统一为Jackery。Reference Details可见块已取消；存量参考字段原样保存和导出。Functional Checks增加按型号的选填故障码多选、页内来源详情与常见故障方案。资料缺英文则明确提示并保留原文，不编造翻译。
- 真实目录9个型号版本、404行候选物料，启用7个型号和261行物料；143行挂起不可选。缺量、型号冲突和停用源信息不能用默认1覆盖。E1000仅可记录检验和故障，其25行耗用仍挂起。

防回退证据：`tests/inspection-override.test.js`、`tests/inspection-override.test.mjs`。浏览器覆盖全部7种结果，均需只有一组检验单选点、无复测输入、无下拉框；API覆盖无新final、旧final保留、ROK无需复测、翻新门禁及历史更正。
