# E2000plus A版未显示修复

用户反馈型号选项缺少E2000plus A。根因：原始BOM根节点有停用标记，源目录将该型号active置为false，GET /api/catalog按启用状态过滤，所以前次只修正SKU后仍不显示。最新用户已确认A/B本体一致并要求A版作业，恢复现有型号，不创建重复modelId。

恢复A版active=true和54条只含parent_model_requires_review的物料active=true；3条另有样机/试产生命周期标记的物料保持挂起。所有57行的SKU、描述、标准用量、source及reviewReasons原值保留；旧来源停用标记不回写，新增availability来源meta记载用户确认、模型ID和启用物料ID。历史工单及快照不变，B版及其余型号不变。不会因A/B本体相同而合并版本或允许任意跨型号物料。

新应用层在真实来源导入后调用幂等修正；已有正式库用显式维护工具，在暂停访问/备份后更新。遇到物料数量不符、生命周期分类不符、正常物料缺标准量或已启用试产物料时整笔拒绝，不自动猜测。执行重复修正不会覆盖管理员后续修改。

新增2项核心单元和1项真实浏览器测试。验证普通作业员目录/下拉含A版、中英文名称、SKU带出、54条可用BOM、按上限选料、保存WFR及API超耗422拒绝，检查历史/其他型号/原量等均不变。全量138核心/API和36浏览器，共174项；最终机器证据见plus-a/VERIFICATION_SUMMARY.json。

预计数据配置为9个来源型号、8个启用型号、404行BOM，其中315启用、89挂起；E1000plus A/B缺资料仍仅登记映射。正式入口继续为800，不修改网络或密码。生产交互不使用未知口令、不写测试单，真实浏览器使用隔离数据；正式库通过只读检查和配置差异校验验证。
