## 实现及兼容性

src/model-sku.js按catalogKey匹配现有主数据，单事务只修改productSku并写一条有来源摘要/差异/待配置项的meta回执。同参考ID重复执行不产生新改动，参考ID内容变更拒绝；遇到未预期的管理员SKU修改，整个事务拒绝，防止覆盖其他变更。缺少来源的型号只列待配置，不自动创建或激活。

scripts/update-model-skus.mjs要求显式指定已有数据库目录，不初始化新目录、不修改密码。原导入CLI和带catalogPath的新实例导入后应用同一确认映射；旧来源批次及其原导入报告保留。既有API路径、字段、权限及状态码不变，model.productSku属于用户授权的主数据更正；历史记录快照和原参考字段不回写。
