# Huabao V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans task-by-task. User explicitly authorized unattended execution; do not request review/confirmation between tasks.

**Goal:** Deliver a runnable, tested V1 matching the approved English EN2+BOM drawer+three grouped outcomes visual.

**Architecture:** Native Node.js HTTP serves a plain ES-module SPA and JSON APIs. SQLite persists users/sessions/catalogs/record snapshots/photos/audit. Authentication, optimistic version checks and domain validation stay server-side. XLSX/CSV/image helpers are pure functions. Production and demonstration data directories are separate.

**Tech Stack:** Node.js 24.22.1 tested, node:sqlite/http/crypto/fs/zlib/test; HTML/CSS/browser ES modules; Playwright 1.62.1 + installed Edge for E2E only; no runtime npm dependencies.

**Spec:** `PRODUCT_CONTRACT.md`, `docs/API_CONTRACT.md`; accepted visual `../outputs/huabao_repair_requirements_20261029/English_EN2_Grouped_Outcomes_v0.4.png`.

## Global Constraints

- Same-page EN/Chinese, EN2 BOM drawer, three grouped result columns, one outcome globally.
- Owner-only ordinary access/export; exact full SN allows other operators' history read-only; no transfer; admin correction requires reason and audit.
- Only model BOM materials, quantity default 1; packaging within BOM; no inventory/pricing/external integrations.
- Refurb initial all pass; repair ROK final all pass; SCRAP reason; WFR unfinished; completed locked.
- Images optional; preserve original uploads and historical names/descriptions; four-sheet XLSX, full selected scope, no silent truncation.
- Explicit save; server validates ownership, schemas, CSRF and versions. No rendered unescaped user input.
- No user questions; defaults recorded; stop after five consecutive failed fixes of one root cause.

## Review Focus

- Permission leakage through direct IDs, image URLs, history search, broad filters and export.
- Concurrent save/correction/photo revisions must not silently overwrite another tab.
- Dirty language switching/model changes/search/pagination must preserve appropriate unsaved entries and warn on incompatible model changes.
- Malformed CSV/ZIP XML/image headers, numeric infinities and formula-like strings must not corrupt records or execute content.
- Admin catalog edits must not rewrite snapshots or turn a valid old WFR record into a different model/checklist.
